# Hh AI online preview

Static interactive demo only. Accounts and orders live in browser storage, with no real account, order, recharge or payment requests. Use test credentials only. The demo cashier has a 20-minute expiry and an explicit simulated-payment button. It contains no usable receiving address. Order polling never marks an unpaid order paid. Demo card keys cannot be redeemed. Real payments require a separately deployed backend and verified gateway notifications.
